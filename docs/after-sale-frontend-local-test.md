## 业务测试场景

1. 待审核售后：只显示“审核通过”和“审核拒绝”。
2. 退货退款审核通过：必须选择公司退货地址，退款金额只读。
3. 买家已寄回：显示“确认收货”，非完好验货结果不允许恢复库存。
4. 换货待商家发出：只显示“确认换货发出”，成功后展示中文换货物流卡片。
5. 退款失败/处理中：退款页分别显示“重新退款”或“查询渠道状态”，详情显示退款渠道与失败原因。
6. 任意详情：凭证、地址、买家物流、商家物流、退款和时间线按后端返回内容显示，不再使用扁平字段拼装。
